# Hammerhall CLI

Клиент кузницы: отправляет решения на проверку и показывает профиль.

## Что это

Курьер между вашей папкой и платформой. Читает файл, отправляет текст,
печатает вердикт. Больше ничего — ни компиляции, ни тестов, ни подсчёта
очков. Всё это происходит на сервере.

## Как пользоваться

Клиент лежит внутри кузницы: клонировали репозиторий — и он уже здесь.
Ставить ничего не надо.

```bash
./hammerhall login                    # вставить токен (спросит, ввод скрыт)
./hammerhall pull MovCode0002         # забрать задачу в свой проект
./hammerhall submit MovCode0002.java  # отправить решение
./hammerhall profile                  # посмотреть профиль
```

`pull` кладёт файл в пакет, объявленный в самом тексте задачи, и **не
затирает** уже существующий файл: если вы решали эту задачу, решение
останется на месте. Перезаписать — `hammerhall pull MovCode0002 --force`.

Windows — то же самое через `hammerhall.bat`.

Файл ищется по имени внутри `src/main/java`, полный путь помнить не нужно.

## Токен

Выдаётся при регистрации на сайте и показывается **один раз**. Потеряли —
перевыпустите в личном кабинете: в базе хранится только хеш, восстановить
нельзя.

Сохраняется в `.hammerhall/config` в корне кузницы. Файл в `.gitignore` —
если вдруг нет, клиент предупредит.

## Сборка

```bash
mvn package
```

Получится `target/cli-0.1.0.jar` — один файл без зависимостей.

## Требования

Java 25 — та же, что нужна для решения задач в кузнице.
