# Hammerhall CLI

Клиент кузницы: отправляет решения на проверку и показывает профиль.

## Что это

Курьер между вашей папкой и платформой. Читает файл, отправляет текст,
печатает вердикт. Больше ничего — ни компиляции, ни тестов, ни подсчёта
очков. Всё это происходит на сервере.

## Как пользоваться

Клиент лежит внутри кузницы: клонировали репозиторий — и он уже здесь.
Ставить ничего не надо.

```bash
./hammerhall login                    # войти по почте и паролю
./hammerhall pull MovCode0002         # забрать задачу в свой проект
./hammerhall submit MovCode0002.java  # отправить решение
./hammerhall profile                  # посмотреть профиль
```

`pull` кладёт файл в пакет, объявленный в самом тексте задачи, и **не
затирает** уже существующий файл: если вы решали эту задачу, решение
останется на месте. Перезаписать — `hammerhall pull MovCode0002 --force`.

Windows — то же самое через `hammerhall.bat`.

Файл ищется по имени внутри `src/main/java`, полный путь помнить не нужно.

## Ключ доступа

`hammerhall login` спрашивает почту и пароль — те же, что на сайте
hammerhall.io, — и получает ключ сам. Пароль вводится скрытно и никуда
не сохраняется. Видеть ключ вам не нужно.

Каждый вход выпускает **новый** ключ, а прежние продолжают работать: дома
и на работе можно войти отдельно, и вход на второй машине не отключает
первую.

Смена пароля отзывает **все** ключи разом — после неё `login` нужен на
каждой машине.

Ключ хранится в `.hammerhall/config` в корне кузницы. Файл в `.gitignore` —
если вдруг нет, клиент предупредит.

Ключ, выпущенный в личном кабинете, тоже подойдёт:

```bash
./hammerhall login --token            # вставить готовый ключ, ввод скрыт
```

⚠️ Ключ **не передаётся аргументом** командной строки: там он остался бы
в истории терминала и был бы виден в списке процессов — то есть утёк бы
ровно туда, откуда мы его прячем, убирая конфиг в `.gitignore`.

## Сборка

```bash
mvn package
```

Получится `target/cli-0.1.3.jar` — один файл без зависимостей.

## Требования

Java 25 — та же, что нужна для решения задач в кузнице.
